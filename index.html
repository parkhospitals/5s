Room Floor Plan — 2D / 3D Wall View

Set the approved location standard here. Only Admin and System Administrator accounts can edit and save the plan. The 3D wall view shows wall-mounted items such as clocks and dispensers.

Each registered asset is placed automatically using its Item Type and Identification Code. Enter actual room width, length and wall height; arrange the icons to match the physical room. 2D and 3D positions are linked. Admin can drag an item to move it; drag the invisible resize area at the bottom-right of an item to resize it and its icon. Use “Draw Room with Mouse” to sketch a custom room boundary. The 3D room shows floor assets and wall-mounted items together. Other users can view the approved plan.
